# ComfyUI-QG-tools

一个 ComfyUI 自定义节点包，目前包含三十二个节点：**LoRA 加载器**、**模型加载器（三合一）**、
**图像裁剪 + 旋转 + 补边**、**工作流说明卡**、**工作流开关**、**运行计时器**、**文本**、
**加载文档**、**Google 翻译**、**任意切换**、**展示任意**、**是否判断**、**字符串切换**、**布尔开关**、
**数值**、**数学运算**、**图像缩放**、
**图像或 Latent 尺寸**、**种子**、**图像水印**、**文字叠加图像**、**宫格图像拼接**、
**图像对比**、**导出图像**、**遮罩上色**、**遮罩拼接**、**文本合并**、**文本替换**、**文本按分隔符分割**、
**尺寸选择器**、**画布标签**、**Markdown 便签**。

**Image Crop + Rotate + Pad —— 在节点上直接把画面摆正、裁好、补出画布**

- **看得见地编辑** —— 节点上就是一块编辑面板：拖动画面旋转、拖角裁切、拖边补边，不用来回改参数
- **补出来的地方自动进遮罩** —— 新补的边、旋转留下的角、原图里透明的地方都算「待生成区域」，一路 `mask` 输出
- **附带缝合器** —— `stitcher` 输出把生成结果贴回原图，接下游的缝合节点即可
- **能出规则尺寸** —— 「Divisible by」让输出的长宽能被 8/16/32 整除，模型和 VAE 都开心

**LoRA Loader —— 把整摞 LoRA 收进一个节点里管**

- **一个节点管整摞 LoRA** —— 列表式的行编辑器，每行能搜文件、拖着调强度、随时开关、拖动排序
- **触发词自动汇总** —— 所有启用行的触发词去重后拼成一路字符串输出，直接接进提示词
- **整摞存成模板** —— 常用的 LoRA 组合存下来，在任何同类节点上一键套用
- **吸收模型链上的 LoRA** —— 把串在模型链上下游的其它 LoRA 加载器全部并进来，原节点自动旁通，**出图结果不变**

**模型加载器 —— 三合一：扩散模型 + CLIP + VAE 一次选完**

- 一个节点顶掉「UNET Loader + Load CLIP + Load VAE」三个节点，输出标准 `MODEL` / `CLIP` / `VAE`
- 下拉列表从本机现读，不绑模型家族；节点上只显示短文件名，不会把画布撑宽

**Workflow Note —— 让别人打开你的工作流就知道怎么用**

- 卡片式说明：大标题 + Markdown 正文 + 作者 + 链接，直接画在节点上
- 列出需要的模型和依赖的节点包，**自动和本机安装对照**，每行标出「✓ 已安装 / 缺失」，并给下载按钮
- 一键「从当前工作流检测」，把图里用到的所有自定义节点包列出来

**Workflow Switches —— 一张卡片集中开关工作流**

- 选中若干节点 → 建一个开关，一键旁通/恢复这一整块（比如「放大 + 保存」这套）
- 也能当参数预设用：为「开」和「关」各存一套选中节点的设置值，一键切换
- 折叠后只剩标签和开关，不占画布

**Run Timer —— 这次跑图花了多久，直接写在画布上**

- 整轮队列的秒表：开始跑就走字，跑完停住总时长
- 右键看最近几次的记录，改完设置好和上一次对比
- 时间跟着工作流一起保存，别人打开你的图就知道作者那次跑了多久

**Text —— 画布上的一块随手文本框**

- 手动敲的字，整段作为一路字符串输出，接给任何下游文本输入
- 纯 Python 节点，零依赖、不加载模型

**加载文档 —— 把 Markdown 文件读成一路文本**

- 下拉里选一个文档（.md / .markdown / .txt 都行），节点上直接预览内容，可以切「渲染视图 / 纯文本视图」、放大看、一键复制
- 输出 STRING，接提示词框、CLIP Text Encode、说明卡都行
- 纯文本模式会剥掉 `#`、`*`、表格线这些标记，读起来像一句提示词；原样模式按文件原封不动输出
- 文件放在 ComfyUI 的 `input` 目录（或它旁边的 `md` / `prompts` 目录），也可以直接在 `custom_path` 填绝对路径

**Google 翻译 —— 用 Google 翻译把提示词译成另一种语言**

- 选源语言（auto 自动识别）和目标语言，节点排队运行（按 Run）时就把 `文本` 输出译成目标语言，可直接接 CLIP Text Encode / 提示词框
- 节点上有一个「手动翻译」按钮：开启 `手动翻译` 开关后，按钮会把文本框里的文字就地翻成目标语言（不影响连线的自动翻译）
- 零额外依赖：免费通道用 ComfyUI 核心自带的 `requests` 直连 Google 接口，无需 API key；若设了环境变量 `GOOGLE_TRANSLATION_API_KEY`，则自动改用官方、不限量的 Google Cloud Translation API
- 免费通道 Google 可能对服务端 IP 限流（HTTP 429），限流或网络异常时节点会原样返回原文而不是报错，流水线不会断

- **任意切换 —— 把多个同类型输入并成一路，输出第一个非空、已连接的那个**
- **展示任意 —— 在节点上直接预览任意输入（文本/图像/遮罩/音频/视频），并原样透传**
- **是否判断 —— 布尔分支：为真走「真时」，为假走「假时」，没走的那路不求值**
- **字符串切换 —— 两段提示词写在节点上，拨一下布尔就换，不用再拉两个文本节点**
- **布尔开关 —— 整张节点就是一枚开关：大号「开 / 关」+ 可点的胶囊，扇出到多个下游条件**
- **数值 —— 整数和浮点合一：一张卡片里一个可拖的数字框，类型在标题栏齿轮里切**
- **数学运算 —— 一行表达式算出一个数：`round(a / b * 2, 2)` 写在一张卡片上，a/b/c… 接上游**
- 常用于接「兜底」：有高清模型就走它，没有就走普通版；节点上接几个、槽位自动增减
- 所有输入必须是同一类型（混接 IMAGE 和 LATENT 会报人话错误），全空时也会报错而不是把 `None` 传给下游

**图像缩放 —— 像素或百分比缩放，顺手裁切 / 补边**

- 度量可选「像素」或「百分比」，适配方式三选一：`crop` 铺满后居中裁、`pad` 放下后居中补、`contain` 只缩不裁
- 宽或高填 0 就按另一边等比推算（此时按 `contain` 处理）
- 除了图像，还把结果的**实际宽高**当整数输出，可直接喂给下游的尺寸运算

**图像或 Latent 尺寸 —— 接什么都告诉你宽高**

- 输入是通配类型，IMAGE / MASK / LATENT 都能接；Latent 内部尺寸是除以 8 存的，这里自动乘回 8
- 输出 WIDTH / HEIGHT 两个整数，用来驱动按尺寸分流的节点

**种子 —— 一张卡片管住一个种子**

- 大号数字框里直接改种子；「随机值 / 固定 / Step」一段决定每次排队之后它怎么变（Step 再点一下变 −1）
- 「新种子」抽一枚并固定、「用上次」把上次真跑过的种子填回来，`▾` 里是最近 8 枚跑过的种子
- 底下一行实时显示「上次运行」用的种子——随机值模式下框里已经是下一枚，靠后端回传的值才准
- 老工作流里 `-1 / -2 / -3` 的写法，打开时自动翻译成「随机值 / Step +1 / Step −1」，连线不用重接

**图像水印 —— 贴水印不用再开修图软件**

- 水印可缩放（等比适配 / 按倍数 / 按指定宽高）、可九宫格锚点定位再加像素偏移、可旋转、可调透明程度
- 底图是批次时逐帧贴同一位置；接一张遮罩还能限定哪些区域**不透出**水印
- 修掉了上游透明度失效的 bug：带 alpha 的水印现在真的按透明程度混合，旋转后的边角也正常

**文字叠加图像 —— 把字直接画进图里**

- 选系统字体、字号、颜色（内置六色或自定义 RGB），横排 / 竖排随意，按中心点坐标定位
- 除了画好的图像，还输出**文字形状的遮罩**，方便后续只在有字的区域做处理
- 批次时每一帧都画同样的字（上游只画了第一帧）

**宫格图像拼接 —— 多图拼成一张，节点上直接看**

- 最多 16 张，默认统一成第一张的尺寸、在格内等比居中不裁剪；可设格间间隙与背景色
- `剔除全黑帧` 开关：上游批次节点给未接输入补的黑图占位可以自动丢掉，也能关掉照常拼进去

**遮罩上色 / 遮罩拼接 —— 遮罩的两件小工具**

- 上色：内置六色或自定义 RGB 把遮罩区域涂成纯色，遮罩按 0.5 硬切；单张遮罩会应用到整批
- 拼接：两张遮罩左右 / 上下拼成一张，输出标准 `(1, H, W)`；可开启尺寸统一，把小图拉到与大图同尺寸

**文本替换 —— 一次配好三组替换**

- 最多三组「查找 → 替换」，规则按 1 → 2 → 3 顺序生效
- **默认字面、正则可选**：字面模式下括号、点号、竖线都是普通字符，提示词里的 `(red:1.3)` 能整段删掉；
  切到正则模式可用 `\d+`、`\1` 反向引用，写错直接报错而不是悄悄退化

**文本按分隔符分割 —— 切掉思考块、拆段落**

- 分隔符支持正则；默认 `<think>` 正好用来切掉模型的思考块
- 三路输出：`全部段落`（合集）、`单条切分`（选定那条输入的完整切分）、`指定段落`（第 N 段）

**文本合并 —— 两段文本拼成一段**

- 就是 `文本1 + 分隔符 + 文本2`，原样拼接、不去空格；想要空格或换行就写进分隔符
- 两个文本都是**输入槽**，从上游连过来；分隔符是文本框，直接填（常用来插「，」「 」或换行）
- 只有一路输出（上游声明了第二路「显示帮助」却从不返回值，这里删掉了）

**尺寸选择器 —— 选好比例，直接出空 Latent**

- 预设分辨率 + 比例下拉，可选长边缩放、百万像素档、宽高对齐倍数、帧数（大于 0 即视频模型）
- `比例` 里选 **`采用比例`** —— 用预设**标签**里写的那条比例。预设的像素往往只是近似
  （`2304×1280` 实际是 9:5，标签标的是 `16:9`），选了它才会按真正的 16:9 算；填任意比例
  用下面一行 `自定义比例`（如 `2.39:1`）
- 潜在通道数可选 4 / 16 —— SD1.5 / SDXL 用 4，Flux / SD3 / 视频模型用 16
- `对齐倍数` 留 0 时不额外取整，但**求解比例 / 百万像素 / 长边时仍保证 8 的倍数** ——
  latent 就是按 8 展开的，非 8 的倍数会被悄悄截断（节点报 1215、图只有 1208）
- 修掉了上游两个 bug：通道数写死 16、以及比例填「无」时长边把宽高都套上导致画面变正方形
- 另外自己修了两个：比例会被「向上取整」带偏（16:9 曾算成 7:4）；输出的 Latent 没声明
  8 倍下采样，16 倍模型上出图会翻倍

**图像对比 —— 一张面板对照 A 和 B**

- 三种看图方式：`滑动`（竖线跟着指针，左边 A 右边 B）、`A`、`B`
- 指针离开后自动停在「结果」那张图上——哪一路是结果按连线判断（B 通常是从 A 改出来的那张）
- A 原样从输出送出，所以这个节点可以夹在流程中间，不影响下游

## Image Crop + Rotate + Pad（裁剪 + 旋转 + 补边）

载入一张图，在节点上的编辑面板里做**一次**旋转 / 裁切 / 补边，输出摆正并补好画布的画面，
外加一份标出「该生成哪里」的遮罩。

### 面板怎么用

| 操作 | 效果 |
|---|---|
| 拖画面 | 平移取景框里的画面 |
| 拖角 / 拖边 | 改裁切框 |
| 旋转 | 顺时针旋转（`rotation_degrees`，-180 ~ 180） |
| 拖画布边 | 给某一边补出 `fill_color` 的边（拖出来的就是 padding） |
| 比例 | `crop_aspect_ratio`：锁定裁切框比例，`free` 任意、`source` 跟随原图 |

面板上的改动会直接写回节点参数，所以保存、撤销、API 调用都走 ComfyUI 原生路径。

### 遮罩里有什么

`mask` 白的地方就是「可以让模型画」的地方：

- 补出来的边（padding）；
- 旋转留下的空角；
- 原图里**透过去**的地方（实心度不足 90% 的像素，比如抠图留下的透明边）。

不想让透明区域被当成待生成区域，把 `painted_area` 设成 `keep picture` —— 底下原样保留，
只靠遮罩标记。

### 缝合器

`stitcher` 是一份「怎么把生成结果贴回原图」的说明，接到下游的缝合节点
（AusBoss 的 Stitch Inpaint，或本插件将来搬过来的同类节点）就能自动对齐贴回。
`stitch_blend` 控制贴回的过渡带宽度，`stitch_grow` 控制贴回边界往哪偏。

### 出规则尺寸

`canvas_multiple`（Divisible by）把输出长宽凑成它的整数倍：有补边的那一侧多补几个像素，
没补边的那一侧就裁掉几个像素（两侧各裁一半）。要 8/16/32 整除的模型设这里，`1` = 关闭。
`resize_to_megapixels` + `megapixels` 可以再把结果缩到指定像素预算（与核心
Scale Image to Total Pixels 同语义）。

### 输入 / 输出

14 个必填 + 7 个可选，全部是画布上的参数；画面上常用的一些
（比如旋转、裁切、补边）藏在面板里，不会挤满节点。

| 输出 | 说明 |
|---|---|
| `image` | 变换后的图像 |
| `mask` | 待生成区域（补边 / 旋转空角 / 透明处） |
| `stitcher` | 缝合器（贴回原图用） |
| `original` | 变换前的原图 |
| `width` / `height` | 输出尺寸 |
| `prompt_image` | 给模型看的提示图（带待生成区域的示意） |

### 自定义比例预设（可选）

把插件根目录的 `qg_presets_example.json` 复制成 `qg_presets.json` 再改，
可以往比例下拉里加自己的 `W:H` 条目。文件里有坏条目只会警告一次并跳过，不影响节点注册。

## LoRA Loader

一个节点管整摞 LoRA：接上 `MODEL`（可选接 `CLIP`），下面排开你要用的所有 LoRA，
输出打好补丁的模型和一行触发词。

### 每一行有什么

| 控件 | 作用 |
|---|---|
| 拖拽手柄 | 按住上下拖动，调整 LoRA 的应用顺序 |
| 开关 | 临时旁通这一行，不必删掉它 |
| 名字 / 选择器 | 点一下打开搜索框挑文件；名字太长会按设置省略 |
| 强度 | 直接在名字上左右拖动就能调，也可以点进数值框；旁边有中心零点强度条 |
| ⓘ | 悬停看预览图、底模、触发词，可顺手查 Civitai |

### 触发词

每个 LoRA 的触发词会自动汇总，**去重**后按 `trigger_separator`（默认 `, `）拼成一路 `triggers`
输出，直接接进提示词。也可以给任意一行**手填自己的触发词**。

有两个刻意的设计：

- 把某行强度调到 **0**，它的触发词**仍然保留** —— 这样对比「用 / 不用这个 LoRA」时只需改权重，提示词不用动。
- 因文件缺失**被跳过**的那一行，不加任何词。

### 整摞存成模板

强度条那一排的 ▤ 按钮可以把当前整摞 LoRA 存成命名模板（存在浏览器本地）。
之后在任何 LoRA Loader 上点开 ▤ 就能一键套用，也能删除。

### 吸收模型链上的 LoRA

齿轮菜单里的 **Absorb chain LoRAs** 会沿本节点的模型链往上下游走，把路上遇到的其它 LoRA 加载器
（包含 rgthree、JPS、Pixaroma 等插件的节点）的 LoRA 全部并进本节点，再把那些节点自动旁通 ——
**出图结果完全不变**，只是整摞 LoRA 集中到了一处管理。

前提是那些节点的 LoRA 不是从连线动态接进来的（例如 rgthree 的 Power Lora Loader 接了外部输入）；
这种情况菜单会提示你先断开。整摞 LoRA 也有行数上限，超出时会提示你先清理几行。

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入（必填） | `model` | 要打 LoRA 补丁的扩散模型 |
| 输入（必填） | `loras` | 序列化的 LoRA 栈，**由面板托管** —— 改行，不要改这个值 |
| 输入（可选） | `clip` | 不接的话 CLIP 强度会被忽略 |
| 输入（可选） | `trigger_separator` | 触发词之间的分隔符，默认 `, `；在齿轮菜单里改，画布上隐藏 |
| 输入（可选） | `on_missing` | 文件缺失时怎么办，见下 |
| 输出 | `model` | 按行顺序打完所有启用 LoRA 的模型 |
| 输出 | `clip` | 同样处理过的 CLIP |
| 输出 | `triggers` | 所有启用行的触发词，去重后拼成的一行字符串 |

### 文件找不到时

- LoRA **只是被移动过**（还在 `loras` 目录里、换了子文件夹）会在运行时按文件名自动找回来，不用管。
- **真的找不到**时，默认行为是**在采样前直接报错停下**，并在错误信息里点名是哪个文件 ——
  无人值守或脚本化跑图不会静默地少打一个 LoRA。
- 想让它在控制台警告一声然后跳过这一行，把齿轮菜单里的 **Stop on missing LoRA** 关掉即可
  （API 调用时对应 `on_missing: "skip"`）。

### 设置

齿轮按钮里是这个节点类型的偏好设置，存在浏览器本地，跟着你所有工作流走：

| 设置 | 默认 | 作用 |
|---|---|---|
| Default strength | 1.0 | 新加一行时的初始强度 |
| Strength step | 0.05 | 拖动与方向键的步长（按住 Shift 恒为 0.01） |
| Separate model / CLIP strength | 关 | 每行显示两个强度框，分别控制模型和 CLIP |
| Strength bars | 开 | 名字后面的中心零点强度条（青色向右为正，红色向左为负） |
| Trigger word separator | `, ` | 拼接 `triggers` 输出用的分隔符 |
| Stop on missing LoRA | 开 | 关掉后，文件缺失只警告并跳过 |
| Hide file extension | 开 | 名字不显示 `.safetensors` |
| Hide folder names | 开 | 只显示文件名（完整路径仍在提示里） |
| Civitai lookup button | 开 | 信息卡里提供「查 Civitai」按钮 |
| Long names | end | 名字太长时怎么省略；`middle` 会保留结尾的数字 |
| Scrub strength on the name | 开 | 在名字上左右拖动改强度（单击仍然是打开选择器） |
| Preview thumbnails | 开 | 悬停选择器时显示预览图 |

## 模型加载器（三合一加载器）

把 **扩散模型 + 文本编码器 + VAE** 三个加载器并成一个节点：三样各选一次，
输出标准 `MODEL` / `CLIP` / `VAE` 三路，接到采样器上即可。原本要摆三个节点、来回改三处下拉，
现在一块面板说完。

- **不绑模型家族** —— 底下跑的就是 ComfyUI 三个原生加载器，下拉里的文件列表、权重类型、
  CLIP 类型、加载设备全部在启动时从本机现读，所以 Qwen-Image / Flux / SD 系列都照常能用；
  ComfyUI 升级后选项自动跟着变，不用等插件更新
- **下拉看全路径，节点上看短名** —— 下拉列表里显示完整路径便于区分同名文件；
  选中之后节点上只留文件名，不会把节点撑宽（存的值仍是真实路径，不会被改写）
- **旧工作流不会断** —— 万一某行存的是裸文件名、或路径分隔符不一样，
  运行时会按文件名在 `models/` 下自动找回；真找不到才报错，并点名是哪个文件

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入（必填） | `unet_name` | UNET / 扩散模型 |
| 输入（必填） | `weight_dtype` | 权重精度，显存紧张可选 `fp8_e4m3fn` |
| 输入（必填） | `clip_name` | CLIP / 文本编码器 |
| 输入（必填） | `clip_type` | 文本编码器类型（Qwen-Image 选 `qwen_image`） |
| 输入（必填） | `device` | 文本编码器加载设备，选 `cpu` 可省显存（速度变慢） |
| 输入（必填） | `vae_name` | VAE |
| 输出 | `MODEL` / `CLIP` / `VAE` | 三路标准输出，直连采样器 |

> 本节点为作者自有节点（ComfyUI-TripleLoader），非第三方搬运。

## Workflow Switches（工作流开关）

把一套工作流拆成几块，用一个节点统一切换。适合对比「开不开这一块」的效果、或者做「快速模式 / 全量模式」。
节点自身不运行，也不接任何线，纯粹是画布控制器。

### 建一个开关

1. 在画布上**选中一组节点**（比如放大节点 + 它的保存节点）。
2. 在开关卡片上点 `+ Switch`。
3. 起个名字（比如「高清放大」）。

之后这个开关就是这一组的 关 | 开 按钮。**关** 默认是旁通（bypass）这些节点，图照常往下传；
在设置里可以改成**静音**（mute，下游拿不到输入会停下）。

### 三种不同粒度的开关

| 类型 | 建在哪 | 控制什么 |
|---|---|---|
| 节点开关 | 选中任意若干节点 | 这一组节点的开/关 |
| 分组开关 | 选一个分组 | 整个分组的开/关 |
| 全局开关 | 设置里的分组策略 | 按「不分组 / 每个分组 / 按编号分组」批量生成 |

打开「**一次一个**」后，打开某一行会自动关掉其它行 —— 适合「两个放大模型二选一」这类场景。

### 当参数预设用

开关不只管开关，也能改参数：选中节点后把当前值存成「开」的一套、改成另一套再存成「关」的一套。
之后一键就能把 Steps 设成 8、打开某个 LoRA 行，而不需要真的旁通任何节点。

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入 | —— | 无 |
| 输出 | —— | 无 |

开关状态存在节点自己的属性里，所以随工作流一起保存。

## 任意切换（动态多输入开关）

把任意数量的同类型输入接到节点上，它会输出**第一个非空、已连接的那个**——
接线时连几个，节点上的槽位就自动增减（最少 2 个、最多 16 个），中间的空槽会保留位置，
所以优先级稳定、不会因为中间断开而错位。

- **接兜底** —— 把「高清模型」接在最上面、「普通模型」接在下面；前者有就走前者，没有自动回落到后者
- **类型要一致** —— 所有输入必须是同一类型。混接（比如一个 IMAGE、一个 LATENT）节点会直接报错说清是哪两种类型，而不是把错的数据喂给下游
- **全空会报错** —— 一个输入都没接、或全是空值时，节点报错提示，而不是默默传一个 `None` 让下游不明所以地崩

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入（可选） | `any_01 … any_16` | 任意类型的输入，接到哪个就出现哪个；输出第一个非空 |
| 输出 | `any` | 第一个非空、已连接的输入（类型与输入一致，连线时槽位会标成具体类型如「图像」） |

## 展示任意（任意输入预览 + 透传）

把任何东西接进 `Any` 口，节点上直接看到内容，同时**原样透传**给下游——调试中间结果
不用再挂 SaveImage / 预览一堆不同类型的节点：

- **什么都能看** —— 文本/整数/浮点/布尔直接显示（布尔带红绿配色）；图像、遮罩出缩略图；
  音频出播放器；视频直接内嵌播放；Latent、张量等显示结构摘要（shape/dtype/device）
- **批量与画册** —— 图像批次自动网格排布，点击放大后 ← / → 键或按钮翻页，Esc 返回
- **文本样式可调** —— 右键「展示文本设置…」可改字号和颜色（INT/FLOAT/BOOLEAN 有默认配色）
- **复制 / 保存** —— 文本悬停出「复制」按钮；图像/音频/视频右键可复制到剪贴板或存盘
- **不影响执行** —— 有下游连接时它按普通依赖执行；没接下游时也会主动执行以刷新预览；
  预览转换失败只记日志，数据照常透传，流水线不会断

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入（可选） | `Any` | 任意类型；槽位会按上游输出类型自动标注（图像/模型/CLIP…） |
| 输出 | `Any` | 输入原样透传，类型一致 |

## 是否判断（布尔懒分支）

条件为真透传「真时」的输入，为假透传「假时」的输入——最直白的 if/else：

- **懒执行** —— 没被选中的那一支**完全不求值**：贵的子图（大模型加载、批量渲染）
  挂在没走的那路上不会跑，也不会因为没连东西而报错
- **任意类型** —— 输入输出都是任意类型，图像、模型、字符串都能接；
  两路的类型最好一致，输出槽会跟随连线显示具体类型

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入 | `是否为真` | 布尔条件（可接比较节点、开关等的布尔输出） |
| 输入（可选） | `真时` / `假时` | 两条分支的值；未选中的一路不求值 |
| 输出 | `输出` | 被选中那一路的值，类型与输入一致 |

> 搬运自 Easy-Use（easy ifElse），GPL-3.0，保留原出处。

## 字符串切换（两段提示词二选一）

同一个节点上放两版提示词，用一个布尔切换输出哪一版 —— 做 A/B 试穿、换风格、开关附加描述时，
不用为每段文字各拉一个文本节点、再各连一根线。

- **两段文本直接写在节点上** —— 上方是「真时文本」，下方是「假时文本」，都不用接线
- **想动态也能接线** —— 把任一文本框拖成输入槽（或直接连上），上游的值会覆盖框里写的
- **没选中的那一路不执行** —— 两个输入都声明了懒执行，挂在假分支上的 LLM 调用、读文件节点不会白跑
- 与「是否判断」的分工：那个切的是**任意类型的槽**，这个切的是**写在节点里的字符串**

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入 | `是否为真` | 布尔条件 |
| 输入 | `真时文本` / `假时文本` | 两段文本；既是可编辑框，也能连线上游 |
| 输出 | `字符串` | 被选中的那一段 |

> 思路参考 Crystools 的 `Switch string`，按本插件约定重写（显示名、中文 tooltip、惰性判断都不同）。

## 布尔开关（整张节点就是一枚开关）

一排布尔条件要一起开、一起关时，一个个去点很烦。这个节点把开关本身放到画布上：整张节点就是
一枚开关 —— 左边一块大字，右边一枚胶囊，点胶囊切换，输出接到多少个下游布尔条件上都行，
切一次全部跟着变。

- **可以起名字** —— 双击卡片（或右键「重命名标签…」）给它起个名字，比如「美颜」「高清加强」；
  输入框就浮在卡片那几个字上面，回车生效、Esc 放弃，不弹窗；留空就退回「开 / 关」。
  一排开关并排时，一眼就知道哪个是哪个
- **一眼看出状态** —— 卡片边框在「开」时变成品牌青色，胶囊滑到右边、底色变绿；名字也随状态
  从灰变亮
- **卡片跟着节点等比放大** —— 拉宽节点，字和胶囊一起变大；高度自动跟随（不会被拉成一条细带）
- **状态就是原生布尔** —— 底下仍是一个普通 BOOLEAN 控件（只是被折叠了），存档、撤销、复制粘贴、
  API 导出都跟原生节点一致
- **右键也能切** —— 节点右键菜单里有「打开 / 关掉」，不用瞄准胶囊
- 只有胶囊吃点击，卡片其它地方照常拖动节点；四角留给缩放

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入 | `标签` | 卡片上显示的名字，留空则显示「开 / 关」。没有输入槽，双击卡片改 |
| 输出 | `布尔值` | 开关状态，可同时连多个下游；槽名画在卡片上方，不会被卡片压住 |

> 交互参考 Goohaitools 的「布尔」（孤海）；卡片配色、等比缩放、命中区都是本项目自己的实现。

## 数值（整数 / 浮点合一）

一个数字，一张卡片：左边一行小字「值」，右边就是一个数字框 ——
**左右拖动改、单击直接输入、右边上下箭头按步进调**（Shift 细调），
跟包里 LoRA 加载器的强度框是同一件东西。

- **类型在标题栏齿轮里** —— `?` 左边那枚齿轮点开是「数值设置」，整数 / 浮点数二选一。
  二选一占一整行下拉太浪费，也容易被动到，所以收进齿轮里
- **类型决定输出** —— 选整数就输出 `INT`（小数四舍五入掉），选浮点就输出 `FLOAT`；
  输出槽的类型也跟着变，连线时一眼能看出给的是哪种
- **步长跟着类型走** —— 整数按 1 走、框里不显示小数点；浮点按 0.1 走、显示两位小数
- **切回整数会取整** —— 卡片里不会有「显示 4、实际 3.7」这种别扭状态
- **值存法跟原生一样** —— 存档、撤销、复制粘贴、API 导出全跟 ComfyUI 自带节点一致
- 一个节点顶两个，不用再纠结拖「整数」还是「浮点数」

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入 | `类型` | 整数 / 浮点数，在标题栏齿轮里切换 |
| 输入 | `值` | 数值本身，拖动 / 单击输入 / 箭头步进 |
| 输出 | `数值` | 类型由「类型」决定，可同时连多个下游 |

> 底层输出类型声明为「任意」（`*`），因为 ComfyUI 的类型是类级静态的、运行时改不了；
> 真正的类型由实际返回值决定，前端只把输出槽的显示类型跟着类型改。

## 数学运算（一行表达式）

卡片上只有一行：写算式。变量是节点左侧的 `a`、`b`、`c`……
需要「宽按高度算」「百分比」「勾股」这类地方，一行写完就行，不用串三个节点。

```
round(a / b * 2, 2)        # 比例算尺寸，留两位
sqrt(a**2 + b**2)          # 勾股
100 * 2                    # 常数直接写进表达式
a if a > b else b          # 取大的那个
```

- **变量只接上游** —— 左上角默认 `a` / `b` / `c` 三个槽，**接满一个就自己长出下一个**（最多 26 个），
  整数（宽度、高度、帧数）、小数、布尔都能接。**没连线时按 0 算** —— 要写常数直接写进表达式，
  卡片上没有数字框
- **一个结果三种给法** —— `数值`（小数）、`整数`（四舍五入）、`布尔`（非零为真），
  写比较式 `a > b` 时直接把 `布尔` 当条件接到下游
- **函数用法有专门的手册** —— 📖 [数学运算 · 表达式与函数手册](https://github.com/live1617/ComfyUI-QG-tools/blob/main/docs/math.md)：
  每个函数做什么、怎么用、有什么上限，都在里面；节点上的 `?` 是速查版
- **算错会说话** —— 语法错、未知名字、除零都会报出原始算式和原因，不会静默返回 0
- **只解析不执行** —— 表达式走语法树白名单，别人分享的工作流带不进代码

| 类别 | 用法 |
|---|---|
| 运算符 | `+` `-` `*` `/` `//`（整除） `%`（取余） `**`（幂） |
| 比较 / 逻辑 | `==` `!=` `>` `<` `>=` `<=`，`and` `or` `not` |
| 条件 | `a if a > b else b` |
| 常量 | `pi` `e` `tau` |
| 取整 | `round(x, n)` `floor` `ceil` `trunc` `abs` `sign` |
| 数值 | `min` `max` `sum` `pow` `sqrt` `log` `log2` `log10` `exp` `hypot` |
| 三角 | `sin` `cos` `tan` `asin` `acos` `atan` `atan2`，`degrees` / `radians` 换角度 |
| 其他 | `int` `float` `bool` `factorial` `gcd` `lcm` `fmod` `copysign` |

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入 | `表达式` | 算式本身，留空输出 0 |
| 输入（可选） | `a` … `z` | 自动增长的变量槽，默认露出 3 个；整数 / 小数 / 布尔都能接，没连线按 0 |
| 输出 | `数值` / `整数` / `布尔` | 同一个结果的三种形态 |

> `^` 是**按位异或**（Python 语义），幂请写 `**`。全角的 `（ ）＋ × ÷` 和比例写法 `3：4` 会自动归一。
> 每个函数的完整用法和例子见 [docs/math.md](https://github.com/live1617/ComfyUI-QG-tools/blob/main/docs/math.md)。

## 尺寸选择器

选好比例，节点直接给出空 Latent 和实际宽高。

- **预设 + 自定义** —— 预设列表覆盖常见比例；也可以在 `比例` 里自己填 `16:9`、`2.39:1`、`1 1`
- **长边缩放** —— `长边` 填 0 用预设原始尺寸，填 N 就把长边缩到 N 并保持比例
- **百万像素** —— `百万像素` 填 `1.0` / `2.0` 就按面积定尺寸，形状仍由比例决定
- **潜在通道数** —— 4 给 SD1.5 / SDXL，16 给 Flux / SD3 / 视频模型（**上游写死 16，这里是可选的**）
- **帧数与对齐** —— `帧数` 大于 0 即视频模型；`对齐倍数` 把宽高贴到 8/16/32 的倍数上
- **比例不漂移** —— 比例和对齐倍数同时生效时按 `w = rx·k`、`h = ry·k` 求解，两个方向
  同时落在网格上、比例仍然精确；上游是「先改比例、再各自向上取整」，会漂（16:9 在 32 下
  曾被算成 1344×768 = 7:4）
- **自动适配模型的下采样倍数** —— 输出的 Latent 会声明「按 8 倍下采样做的」，16 倍的模型
  （Qwen Image 2.x、Flux 2 Klein）由采样器自己换算；缺了这个声明，出图会正好是设定值的两倍

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入 | `预设尺寸` / `批次大小` | 起手尺寸与批大小 |
| 输入 | `长边` / `比例` / `帧数` / `对齐倍数` / `潜在通道数` | 尺寸微调 |
| 输入（可选） | `宽（覆盖）` / `高（覆盖）` | 接任意数值，大于 0 就优先用它 |
| 输入（可选） | `百万像素` | 0 = 不用；非 0 就按这个面积定尺寸 |
| 输出 | `Latent` / `宽` / `高` / `帧数` | 空潜在张量 + 实际使用的数值 |

> 搬运自 ComfyUI_Muye（尺寸选择器），MIT，保留原出处。

## 图像对比

两个版本（改前 / 改后）的图放在一起看，不用来回开关节点。

- **滑动** —— 指针在画面上移动，竖线跟着走：左边露出 A，右边露出 B。A / B 两个小标签骑在竖线两侧
- **只看 A / 只看 B** —— 点下面切换条上的 `A` 或 `B`，面板就锁在那一张
- **擦除** —— 一张图压在另一张上，画笔把上面那张擦掉一块，露出底下那张。
  工具行里能改笔宽、软度、哪张在上面，`撤销` / `清空` 管笔迹：
  - 键盘：`[` `]` 改笔宽，`Shift` + `[` `]` 改软度，`E` 擦、`B` 画回来，
    `Ctrl+Z` 撤销、`Esc` 取消正在画的这笔
  - 鼠标：按住 `Ctrl` 或鼠标右键，做当前工具的反面；`Alt` + 右键拖动直接调笔
  - **保存** —— 把混合图按原尺寸写进 ComfyUI 的 output 目录（不是把预览放大）。
    勾上 `PSD` 会另存一个双层 PSD（笔迹作上面那层的图层蒙版）和一张遮罩 PNG
  - **复制** —— 直接进剪贴板，粘到编辑器或聊天窗（只限 localhost / https 打开的页面）
- **停在结果上** —— 指针离开画面后回到「结果」那张。哪一路算结果按连线判断：
  B 默认是从 A 改出来的那张；如果 B 反过来喂给「做 A 的那张图」的来源，就改按 A 算。
  设置里可以关掉（`QG-tools › 图像对比 › 停在结果上`），关掉后就近吸到整张
- **原样透传** —— 输出就是输入 A 的整批图，所以节点可以夹在流程中间，下游照常跑

### 输入 / 输出

| 方向 | 名称 | 说明 |
|---|---|---|
| 输入 | `图像 A` / `图像 B` | 两路 IMAGE，各取第一帧做预览 |
| 可选输入 | `文件名` | 接一根线进来给保存的文件起名（比如源图的文件名）；目录和扩展名会被去掉。不接就用擦除行里打的名字 |
| 输出 | `图像` | 输入 A 原样送出 |

> 笔迹存的是**笔画**而不是位图，所以保存时是按原图尺寸重画的，跟面板显示多大无关；
> 换了图（尺寸变了）旧笔迹会自动丢掉。

## Nodes 2.0（Vue 渲染）

ComfyUI 新版可以把节点渲染成 Vue 组件（设置里的「Nodes 2.0 / Vue 渲染」）。
开启后画布不再调用节点自己的 `onDrawForeground`，所以**把界面画在 canvas 上的节点会整块消失**。
本包把这类节点全部迁到了 DOM，两种渲染模式下表现一致：

- **标注 / 便签**：画布标签、Markdown 便签
- **数值 / 开关**：数值、布尔开关、运行计时
- **图像**：导出图像（含概要行与齿轮）

其余节点（各类加载器、显示任意、文本替换、加载文档、数学运算……）本来就以 DOM 卡片
或原生控件呈现，两种模式下一直在。

几个要点：

- **就地切换，不重载工作流** —— 改设置的那一刻，节点自己从旧容器搬到新外壳，位置、连线、
  选中状态、正在编辑的文字全部保留；撤销栈也不会被清掉。
- **双击进入编辑**（标签 / 便签类）—— Vue 模式下单击被用来拖节点，所以编辑改成双击，
  阈值放宽到 750ms，手慢一点也算。
- **不出双影** —— Vue 模式下 `draw()` 直接短路，画布上不重复画一遍。
- **尺寸按外壳换算** —— Vue 会额外加 30px 标题栏和最小宽度，插件按它算节点尺寸，
  切换瞬间节点不会突然变宽变高。

## QG 节点的外观

所有 QG 节点共用一个配色扩展：

- 新建节点时按当前配色方案自动上色，标题栏带一个 `?` 徽章（点开是说明）。
- 右键任意 QG 节点 → **QG 配色**，可以单独改这一个节点，或者换整套配色方案。
- 已经手动挑过颜色的节点**不会被自动覆盖** —— 想统一就点配色子菜单最后一项
  「把所有 QG 节点重刷为当前配色」（选 `Theme default` 即为清色）。

---

## 中文界面

- 插件自带 `locales/zh/nodeDefs.json`：把 ComfyUI 语言切成中文即生效，节点名、输入输出、提示都会变中文。
- 装了 [ComfyUI-Chinese-Translation](https://github.com/DrippyForever/ComfyUI-Chinese-Translation)
  这类汉化插件时，本包还额外提供前端面板文案的汉化（按钮、菜单、状态提示）。
- 节点标题不带 `QG` 前缀（分类仍在 `QG-tools` 下），所以标题栏干净、搜索框里也不会被一串同名前缀刷屏。

## 中英文搜索

节点标题是中文，但用英文照样搜得到：每个节点都登记了一组英文叫法
（`web/shared/node_aliases.mjs`），页面加载时写进节点定义的 `search_aliases`，
ComfyUI 的搜索框会把它们和标题一起做模糊匹配。

| 想找 | 可以搜 |
|---|---|
| 图像对比 | `compare` / `image compare` / `ab compare` / `diff` / `before after` |
| 图像水印 | `watermark` / `logo` / `stamp` |
| 图像裁剪 + 旋转 + 补边 | `crop` / `rotate` / `pad` / `outpaint` |
| 模型加载器 | `triple loader` / `model loader` / `checkpoint` / `unet clip vae` |
| 尺寸选择器 | `size selector` / `aspect ratio` / `resolution` |
| 遮罩上色 / 拼接 | `mask colorize` / `mask concat` / `merge masks` |

想加词就改 `web/shared/node_aliases.mjs` 里对应节点那一行，刷新页面即可。

**命中别名的节点会往前提一点，但最多 2 个。** 这不是多余的设计：搜索框只取前 64 条，
而 `text` 这类词能命中 480 多个节点，QG 文本原本排第 159 名——等于搜不到。所以扩展会把
「别名里正好有这个词」的 QG 节点提到前面，最多提 2 个，其余保持原位。

搜 `image` 这种上位词时是 `QG 图像缩放`、`QG 图像水印` 排前两位，第 3 个就是原生节点；
搜 `text` 时是 `QG 文本`、`QG 文本按分隔符分割` 排前两位。不想看到这个行为的话，
把 `web/shared/node_aliases.mjs` 末尾那几个上位词（`image` / `mask` / `size` / `model` /
`document` / `workflow` / `text`）删掉即可，节点自己的英文名还会保留。

## 生效与排障

1. 首次安装要**完整重启 ComfyUI**（不是刷新页面）。
2. 之后前端有更新时，浏览器要 `Ctrl+Shift+R` 强刷 —— ComfyUI 只在页面加载时读一次扩展列表。
   （本插件的前端子模块都带版本串，正常情况下普通 F5 也能拿到新代码。）
3. 后端共 16 条路由（LoRA 6 条 + 文档 3 条 + Google 翻译 1 条 + 图像面板的视频预览 4 条 +
   图像对比保存 1 条 + 版本探针 1 条），可用这条命令快速自检：

   ```bash
   curl http://127.0.0.1:8188/qg/pack_version
   curl http://127.0.0.1:8188/qg/lora/list
   ```
