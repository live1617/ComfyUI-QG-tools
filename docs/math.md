# 数学运算 · 表达式与函数手册

「数学运算」节点（`QG_Math`）在卡片上写一行表达式：**算数、拼文本都行**。
这份手册是节点 `?` 帮助卡里那串函数清单的详细版：每个函数做什么、怎么用、
有什么限制。

> 想直接看例子：跳到最后的[常见写法](#常见写法)。

---

## 变量怎么用

节点左侧有 `a`、`b`、`c`…… 一组输入槽，名字就是变量名：

| 特性 | 说明 |
|---|---|
| 名字 | `a` 到 `z`，按字母顺序出现 |
| 数量 | 默认 3 个（`a`/`b`/`c`），**接满一个就自动长下一个**，最多 26 个 |
| 类型 | 整数（`INT`）、小数（`FLOAT`）、布尔（`BOOLEAN`）、文本（`STRING`）都能接 |
| 没连线 | 按 **0** 算 |
| 接文本 | 整串是个数字（`1024`、`" 3.5 "`）就当数字用；否则原样当文本；空白串按 0 算 |
| 空着的槽 | 永远留一个，接上就能用，不用手动加槽 |

**卡片上没有数字框。** 要写常数，直接写进表达式：

```
100 * 2            # 200
a / 2 + 0.5        # a 接上游，其余是常数
```

因为没连线的变量就是 0，所以 `a + 1` 在 `a` 悬空时得 `1`。

## 运算符

| 类别 | 写法 | 说明 |
|---|---|---|
| 算术 | `+` `-` `*` `/` | 加减乘除（`+` 有一侧是文本时变拼接，`*` 一侧文本一侧整数时变重复） |
| 整除 / 取余 | `//` `%` | `7 // 2` = 3，`7 % 2` = 1 |
| 幂 | `**` | `2 ** 10` = 1024（`^` 是异或，别用错） |
| 比较 | `==` `!=` `>` `<` `>=` `<=` | 结果是 0 / 1；两侧都是文本时按字典序比 |
| 包含 | `in` `not in` | `"x" in a`、`3 in [1, 2, 3]` |
| 下标 / 切片 | `a[0]` `a[1:4]` `a[:3]` `a[-1]` | 文本和列表都能用 |
| 逻辑 | `and` `or` `not` | 非零为真 |
| 条件 | `a if 条件 else b` | 条件成立取 a，否则取 b |
| 位运算 | `&` `\|` `^` `<<` `>>` `~` | 按整数位操作 |

比较和逻辑可以直接当条件用，例如 `a > b` 的「布尔」输出就是 `true`。

## 文本

文本写在引号里，跟 Python 一样用单引号或双引号都行：

```python
"a cat" + ", best quality"   # 拼接：a cat, best quality
"ab" * 3                     # 重复：ababab
a + "x"                      # 数字拼进文本会自动写成人读的样子（1024 + "px" → 1024px）
```

**`+` 只要有一侧是文本就是拼接**，不会猜你的意图。想算数就先转：

```python
float(a) + 1                 # a 是 "1024" 这种文本时先转数字
str(round(a / b * 2, 2))     # 数字转文本再拼
```

文本函数都是「函数形式」，不是 `a.upper()` 那种写法（引擎不允许属性访问）：

| 函数 | 说明 | 例子 |
|---|---|---|
| `len(s)` | 长度（文本或列表） | `len("abc")` → 3 |
| `str(x)` | 转文本 | `str(1024)` → `"1024"` |
| `upper(s)` / `lower(s)` | 全大写 / 全小写 | `upper("ab")` → `"AB"` |
| `title(s)` / `capitalize(s)` | 词首大写 / 首字母大写 | `title("a cat")` → `"A Cat"` |
| `swapcase(s)` | 大小写互换 | `swapcase("aB")` → `"Ab"` |
| `strip(s)` / `lstrip(s)` / `rstrip(s)` | 去掉两端空白 | `strip("  a  ")` → `"a"` |
| `replace(s, 旧, 新)` | 替换全部 | `replace(a, " ", "_")` |
| `split(s, 分隔符)` | 切成列表，不填分隔符时按空白切 | `split("a,b", ",")` → `["a", "b"]` |
| `join(分隔符, 列表)` | 用分隔符拼列表 | `join("-", ["x", "y"])` → `"x-y"` |
| `find(s, 子串)` / `rfind` | 找位置，找不到是 −1 | `find("abc", "b")` → 1 |
| `count(s, 子串)` | 出现几次 | `count("aXa", "a")` → 2 |
| `startswith(s, 前缀)` / `endswith` | 判断开头 / 结尾（布尔） | `startswith(a, "a ")` |
| `zfill(s, 宽度)` | 左边补 0 | `zfill(str(7), 3)` → `"007"` |

列表也可以直接写出来：`["a", "b"]`，配合 `join("-", ["a", "b"])` 用。
`sum([a, b, c])`、`min([a, b])`、`max([a, b])` 这些带列表的写法本来就支持。

## 函数

### 取整与符号

| 函数 | 说明 | 例子 |
|---|---|---|
| `round(x)` | 四舍五入到整数，正好 .5 时**远离零**（`round(2.5)` → 3、`round(-2.5)` → −3） | `round(2.6)` → 3 |
| `round(x, n)` | 保留 n 位小数（n 在 −15…15），同样 .5 远离零。先把值放大 10ⁿ 倍再舍入，所以 `round(2.675, 2)` 得 **2.68**（Python 内置 `round` 因二进制表示给 2.67） | `round(1.2345, 2)` → 1.23 |
| `floor(x)` | 向下取整 | `floor(2.9)` → 2 |
| `ceil(x)` | 向上取整 | `ceil(2.1)` → 3 |
| `trunc(x)` | 截掉小数部分（向零取整） | `trunc(-2.7)` → −2 |
| `int(x)` | 转整数（同截断，绝对值上限 1e15） | `int(892.6)` → 892 |
| `float(x)` | 转小数 | `float(3)` → 3.0 |
| `abs(x)` | 绝对值 | `abs(-5)` → 5 |
| `fabs(x)` | 绝对值（走 math，结果一定是小数） | `fabs(-5)` → 5.0 |
| `sign(x)` | 符号：正数 1、负数 −1、零 0 | `sign(-3)` → −1 |

> 像素尺寸建议用 `round`，`floor` / `ceil` 容易让结果偏一个像素。

### 数值与幂

| 函数 | 说明 | 例子 |
|---|---|---|
| `min(a, b, …)` | 最小值（可多参数） | `min(a, b)` |
| `max(a, b, …)` | 最大值 | `max(a, 512)` |
| `sum(a, b, …)` | 求和（也接受列表） | `sum(a, b, c)` |
| `pow(a, b)` | 幂，等同 `a ** b`（指数上限 512） | `pow(2, 8)` → 256 |
| `sqrt(x)` | 平方根 | `sqrt(144)` → 12 |
| `hypot(a, b, …)` | 勾股 / 多维长度 | `hypot(3, 4)` → 5 |
| `dist(p, q)` | 两点距离，参数是列表 | `dist([0, 0], [3, 4])` → 5 |
| `prod([…])` | 连乘 | `prod([2, 3, 4])` → 24 |
| `fsum([…])` | 精确求和（浮点误差更小） | `fsum([0.1, 0.2])` |
| `fmod(a, b)` | 浮点取余 | `fmod(7.5, 2)` → 1.5 |
| `copysign(a, b)` | 把 b 的符号给 a | `copysign(3, -1)` → −3 |

### 指数与对数

| 函数 | 说明 | 例子 |
|---|---|---|
| `exp(x)` | e 的 x 次方 | `exp(1)` ≈ 2.718 |
| `log(x)` | 自然对数 | `log(e)` → 1 |
| `log(x, base)` | 指定底数的对数 | `log(8, 2)` → 3 |
| `log2(x)` | 以 2 为底 | `log2(1024)` → 10 |
| `log10(x)` | 以 10 为底 | `log10(1000)` → 3 |

### 三角与角度

| 函数 | 说明 |
|---|---|
| `sin(x)` `cos(x)` `tan(x)` | 三角函数，**参数是弧度** |
| `asin(x)` `acos(x)` `atan(x)` | 反三角函数，结果是弧度 |
| `atan2(y, x)` | 由坐标求角度（能分象限） |
| `degrees(rad)` | 弧度 → 角度 |
| `radians(deg)` | 角度 → 弧度 |
| `sinh` `cosh` `tanh` | 双曲函数 |
| `asinh` `acosh` `atanh` | 反双曲函数 |

写角度要换算：`sin(radians(30))` → 0.5。

### 整数运算

| 函数 | 说明 | 例子 |
|---|---|---|
| `factorial(n)` | 阶乘，n 在 0…300 | `factorial(5)` → 120 |
| `gcd(a, b)` | 最大公约数 | `gcd(12, 18)` → 6 |
| `lcm(a, b)` | 最小公倍数（任一为 0 时得 0） | `lcm(4, 6)` → 12 |

### 判断

| 函数 | 说明 |
|---|---|
| `isnan(x)` | 是不是非数字 |
| `isinf(x)` | 是不是无穷 |
| `isfinite(x)` | 是不是有限值 |

判断类返回 0 / 1，可以直接拿来当条件。

## 输出

同一个结果给四种形态，接哪个取决于下游要什么：

| 输出 | 内容 |
|---|---|
| `数值` | 原样小数（`FLOAT`） |
| `整数` | 四舍五入（正好 .5 时远离零：`2.5` → 3）后夹在 INT32 范围内（`INT`） |
| `布尔` | 非零为真（`BOOLEAN`），写比较式时直接当条件 |
| `文本` | 结果当文本（`STRING`）：数字按人写的样子（`1024` 而不是 `1024.0`），文本原样 |

**结果是文本时，前三个数字输出一律给 `0` / `0` / `false`。** 这样下游拿不到
一段算不上数的文字当尺寸用，出问题会立刻暴露，而不是悄悄算出 0×0。

## 常见写法

```python
round(a / b * 2, 2)          # 比例算尺寸，留两位小数
sqrt(a**2 + b**2)            # 勾股：由宽高算对角线
round(a * 0.75)              # 按 75% 缩放
a if a > b else b            # 取两者较大的
max(512, round(a / 64) * 64) # 夹到 512 以上，并对齐 64
round(16 / 9 * 720)          # 16:9 里由高算宽
(abs(a - b) <= 8)            # 两个尺寸差在 8 以内（布尔输出）
```

文本类：

```python
a + ", best quality"                  # 在提示词后面接一段（接「文本」输出）
", ".join([a, b, c])                  # 三段提示词用逗号连起来
str(round(w * 0.75)) + "x" + str(round(h * 0.75))   # 拼出 "768x432"
upper(a[:1]) + lower(a[1:])           # 首字母大写
replace(a, "blurry", "sharp")         # 换掉某个词
a if len(a) > 10 else a + ", detailed"  # 太短就补一句
```

尺寸类建议用 `round(...)` 再走「整数」输出，或者套 `* 8 // 8` 对齐到 8 的倍数。
拼尺寸文本时走「文本」输出：`str(w) + "x" + str(h)`，数字不会带 `.0`。

## 限制与报错

**语法**

- `^` 是**按位异或**，幂要写 `**`
- 全角的 `（ ）＋ × ÷` 和比例写法 `3：4` 会自动归一成半角
- 表达式节点数上限 400，别写成一整段程序

**数值上限**

| 项目 | 上限 |
|---|---|
| 幂的指数 | 512 |
| `pow` / `int` 的底数或数值 | 1e15 |
| `round` 的小数位 | −15 … 15 |
| `factorial` 的参数 | 0 … 300 |
| 一段文本的长度 | 10000 个字符（拼接、重复、`replace`、`join` 都会卡） |
| 列表的项数 | 1000 |
| 表达式本身 | 2000 个字符 / 400 个语法节点 |

**算不出来会报错**

语法错、未知函数、除零、参数类型不对，都会在节点红框里给出**原始表达式 + 原因**，
不会静默返回 0。结果算成 `inf` 或 `NaN` 也直接报错（不是有限数，下游当尺寸用会炸），
不会悄悄变成 0。文本做算术（`"abc" - 1`）、下标越界、`len(数字)` 也一样报中文错，
并告诉你该怎么改（比如「要算数先用 float() 或 int() 转成数字」）。

**只解析不执行**

表达式会先解析成语法树，再按白名单逐个节点求值，不走 Python 的 `eval`。
别人分享的工作流里塞不进可执行代码。

## 和 ComfyUI 官方「数学表达式」的差别

| | 官方 Math Expression | QG 数学运算 |
|---|---|---|
| 输入类型 | 浮点 / 整数 / 布尔 | 浮点 / 整数 / 布尔 / **文本** |
| 输出 | 浮点 / 整数 / 布尔 | 浮点 / 整数 / 布尔 / **文本** |
| 变量 | a–z，接满自动增长，留 1 个空位 | a–z，接满自动增长，留 **1 个**空位、起步 3 个 |
| 常量 | 无（π 要手写） | `pi` `e` `tau` `inf` |
| 函数 | 14 个 | 50 多个（含文本函数） |
| 文本拼接 | 不支持（要另接文本节点） | `a + ", best"` 一行搞定 |
| 结果非数字（`inf` / `NaN`） | 报错 | 报错 |

两边都支持 `+ - * / // % **`、比较、`and/or/not`、三元表达式，
官方那套 `sum(values)` 的列表写法在这里也能用（写成 `sum([a, b, c])`）。
