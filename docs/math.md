# 数学运算 · 表达式与函数手册

「数学运算」节点（`QG_Math`）在卡片上写一行表达式，算出一个数。这份手册是
节点 `?` 帮助卡里那串函数清单的详细版：每个函数做什么、怎么用、有什么限制。

> 想直接看例子：跳到最后的[常见写法](#常见写法)。

---

## 变量怎么用

节点左侧有 `a`、`b`、`c`…… 一组输入槽，名字就是变量名：

| 特性 | 说明 |
|---|---|
| 名字 | `a` 到 `z`，按字母顺序出现 |
| 数量 | 默认 3 个（`a`/`b`/`c`），**接满一个就自动长下一个**，最多 26 个 |
| 类型 | 整数（`INT`）、小数（`FLOAT`）、布尔（`BOOLEAN`）都能接 |
| 没连线 | 按 **0** 算 |
| 空着的槽 | 永远留一个，接上就能用，不用手动加槽 |

**卡片上没有数字框。** 要写常数，直接写进表达式：

```
100 * 2            # 200
a / 2 + 0.5        # a 接上游，其余是常数
```

因为没连线的变量就是 0，所以 `a + 1` 在 `a` 悬空时得 `1`。

## 运算符

| 类别 | 写法 | 说明 |
|---|---|---|
| 算术 | `+` `-` `*` `/` | 加减乘除 |
| 整除 / 取余 | `//` `%` | `7 // 2` = 3，`7 % 2` = 1 |
| 幂 | `**` | `2 ** 10` = 1024（`^` 是异或，别用错） |
| 比较 | `==` `!=` `>` `<` `>=` `<=` | 结果是 0 / 1 |
| 逻辑 | `and` `or` `not` | 非零为真 |
| 条件 | `a if 条件 else b` | 条件成立取 a，否则取 b |
| 位运算 | `&` `\|` `^` `<<` `>>` `~` | 按整数位操作 |

比较和逻辑可以直接当条件用，例如 `a > b` 的「布尔」输出就是 `true`。

## 函数

### 取整与符号

| 函数 | 说明 | 例子 |
|---|---|---|
| `round(x)` | 四舍五入到整数 | `round(2.6)` → 3 |
| `round(x, n)` | 保留 n 位小数（n 在 −15…15） | `round(1.2345, 2)` → 1.23 |
| `floor(x)` | 向下取整 | `floor(2.9)` → 2 |
| `ceil(x)` | 向上取整 | `ceil(2.1)` → 3 |
| `trunc(x)` | 截掉小数部分（向零取整） | `trunc(-2.7)` → −2 |
| `int(x)` | 转整数（同截断，绝对值上限 1e15） | `int(892.6)` → 892 |
| `float(x)` | 转小数 | `float(3)` → 3.0 |
| `abs(x)` | 绝对值 | `abs(-5)` → 5 |
| `fabs(x)` | 绝对值（走 math，结果一定是小数） | `fabs(-5)` → 5.0 |
| `sign(x)` | 符号：正数 1、负数 −1、零 0 | `sign(-3)` → −1 |

> 像素尺寸建议用 `round`，`floor` / `ceil` 容易让结果偏一个像素。

### 数值与幂

| 函数 | 说明 | 例子 |
|---|---|---|
| `min(a, b, …)` | 最小值（可多参数） | `min(a, b)` |
| `max(a, b, …)` | 最大值 | `max(a, 512)` |
| `sum(a, b, …)` | 求和（也接受列表） | `sum(a, b, c)` |
| `pow(a, b)` | 幂，等同 `a ** b`（指数上限 512） | `pow(2, 8)` → 256 |
| `sqrt(x)` | 平方根 | `sqrt(144)` → 12 |
| `hypot(a, b, …)` | 勾股 / 多维长度 | `hypot(3, 4)` → 5 |
| `dist(p, q)` | 两点距离，参数是列表 | `dist([0, 0], [3, 4])` → 5 |
| `prod([…])` | 连乘 | `prod([2, 3, 4])` → 24 |
| `fsum([…])` | 精确求和（浮点误差更小） | `fsum([0.1, 0.2])` |
| `fmod(a, b)` | 浮点取余 | `fmod(7.5, 2)` → 1.5 |
| `copysign(a, b)` | 把 b 的符号给 a | `copysign(3, -1)` → −3 |

### 指数与对数

| 函数 | 说明 | 例子 |
|---|---|---|
| `exp(x)` | e 的 x 次方 | `exp(1)` ≈ 2.718 |
| `log(x)` | 自然对数 | `log(e)` → 1 |
| `log(x, base)` | 指定底数的对数 | `log(8, 2)` → 3 |
| `log2(x)` | 以 2 为底 | `log2(1024)` → 10 |
| `log10(x)` | 以 10 为底 | `log10(1000)` → 3 |

### 三角与角度

| 函数 | 说明 |
|---|---|
| `sin(x)` `cos(x)` `tan(x)` | 三角函数，**参数是弧度** |
| `asin(x)` `acos(x)` `atan(x)` | 反三角函数，结果是弧度 |
| `atan2(y, x)` | 由坐标求角度（能分象限） |
| `degrees(rad)` | 弧度 → 角度 |
| `radians(deg)` | 角度 → 弧度 |
| `sinh` `cosh` `tanh` | 双曲函数 |
| `asinh` `acosh` `atanh` | 反双曲函数 |

写角度要换算：`sin(radians(30))` → 0.5。

### 整数运算

| 函数 | 说明 | 例子 |
|---|---|---|
| `factorial(n)` | 阶乘，n 在 0…300 | `factorial(5)` → 120 |
| `gcd(a, b)` | 最大公约数 | `gcd(12, 18)` → 6 |
| `lcm(a, b)` | 最小公倍数（任一为 0 时得 0） | `lcm(4, 6)` → 12 |

### 判断

| 函数 | 说明 |
|---|---|
| `isnan(x)` | 是不是非数字 |
| `isinf(x)` | 是不是无穷 |
| `isfinite(x)` | 是不是有限值 |

判断类返回 0 / 1，可以直接拿来当条件。

## 输出

同一个结果给三种形态，接哪个取决于下游要什么：

| 输出 | 内容 |
|---|---|
| `数值` | 原样小数（`FLOAT`） |
| `整数` | 四舍五入后夹在 INT32 范围内（`INT`） |
| `布尔` | 非零为真（`BOOLEAN`），写比较式时直接当条件 |

## 常见写法

```python
round(a / b * 2, 2)          # 比例算尺寸，留两位小数
sqrt(a**2 + b**2)            # 勾股：由宽高算对角线
round(a * 0.75)              # 按 75% 缩放
a if a > b else b            # 取两者较大的
max(512, round(a / 64) * 64) # 夹到 512 以上，并对齐 64
round(16 / 9 * 720)          # 16:9 里由高算宽
(abs(a - b) <= 8)            # 两个尺寸差在 8 以内（布尔输出）
```

尺寸类建议用 `round(...)` 再走「整数」输出，或者套 `* 8 // 8` 对齐到 8 的倍数。

## 限制与报错

**语法**

- `^` 是**按位异或**，幂要写 `**`
- 全角的 `（ ）＋ × ÷` 和比例写法 `3：4` 会自动归一成半角
- 表达式节点数上限 400，别写成一整段程序

**数值上限**

| 项目 | 上限 |
|---|---|
| 幂的指数 | 512 |
| `pow` / `int` 的底数或数值 | 1e15 |
| `round` 的小数位 | −15 … 15 |
| `factorial` 的参数 | 0 … 300 |

**算不出来会报错**

语法错、未知函数、除零、参数类型不对，都会在节点红框里给出**原始表达式 + 原因**，
不会静默返回 0。结果是 `NaN` 时按 0 处理（下游当尺寸用也不会炸）。

**只解析不执行**

表达式会先解析成语法树，再按白名单逐个节点求值，不走 Python 的 `eval`。
别人分享的工作流里塞不进可执行代码。

## 和 ComfyUI 官方「数学表达式」的差别

| | 官方 Math Expression | QG 数学运算 |
|---|---|---|
| 输入类型 | 浮点 / 整数 / 布尔 | 浮点 / 整数 / 布尔（相同） |
| 变量 | a–z，接满自动增长，留 1 个空位 | a–z，接满自动增长，留 **1 个**空位、起步 3 个 |
| 常量 | 无（π 要手写） | `pi` `e` `tau` `inf` |
| 函数 | 14 个 | 30 多个 |
| 结果非数字 | 报错 | 按 0 处理 |

两边都支持 `+ - * / // % **`、比较、`and/or/not`、三元表达式，
官方那套 `sum(values)` 的列表写法在这里也能用（写成 `sum([a, b, c])`）。
