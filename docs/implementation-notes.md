## Nodes 2.0（Vue 渲染）适配

ComfyUI 新版可以把节点渲染成 Vue 组件（设置里的「Nodes 2.0 / Vue 渲染」）。
开启后画布不再调用节点自己的 `onDrawForeground`，所以**把界面画在 canvas 上的节点会整块消失**。
本包把这类节点全部迁到了 DOM，两种渲染模式下表现一致：

- **数值 / 开关**：数值、布尔开关、运行计时
- **图像**：导出图像（含概要行与齿轮）

其余节点（各类加载器、显示任意、文本替换、加载文档、数学运算……）本来就以 DOM 卡片
或原生控件呈现，两种模式下一直在。

实现要点：

- **就地切换，不重载工作流** —— 改设置的那一刻，节点自己从旧容器搬到新外壳，位置、连线、
  选中状态、正在编辑的文字全部保留；撤销栈也不会被清掉。
- **双击进入编辑**（标签 / 便签类）—— Vue 模式下单击被用来拖节点，所以编辑改成双击，
  阈值放宽到 750ms，手慢一点也算。
- **不出双影** —— Vue 模式下 `draw()` 直接短路，画布上不重复画一遍。
- **尺寸按外壳换算** —— Vue 会额外加 30px 标题栏和最小宽度，插件按它算节点尺寸，
  切换瞬间节点不会突然变宽变高。
- **导出图像的布局两种模式一致** —— 概要行（如 `JPEG · 90 · 4:4:4 · 白底 · ComfyUI`）
  贴在节点底部、文字左对齐；设置齿轮在标题栏 `?` 徽章左侧，点它打开参数面板。

## 采样预览：不重启按工作流切换的机制

新版 ComfyUI 在读 `extra_data["preview_method"]`（`PromptExecutor.execute_async`
第一行就是 `set_preview_method(...)`，传 `None` 则恢复启动默认）。采样预览节点在排队**之前**由
`PromptServer.add_on_prompt_handler` 改写这个字段，一个字节的后端代码都没打补丁；
下个工作流不带这个节点，字段自然为空，ComfyUI 自己就复位了。

画面由 ComfyUI 的采样器自己逐步骤发出来，前端把那些帧接进节点里的画布；
STOP 调的是 ComfyUI 自己的中断接口，和工具栏上那个「取消」是同一个。

老版本 ComfyUI 没有 `extra_data` 字段时，退化成节点执行时直接改全局设置 ——
只能影响它之后执行的采样器，精度差一点，但总比整台服务器重启强。

## 中文界面：语言包与英文值

后端代码里写的是英文（节点标题、输入输出名、提示文字、下拉选项的值），中文来自插件
自带的 `locales/zh/nodeDefs.json`，ComfyUI 语言切到中文时自动叠上去。两边的对应关系
由 `tools/verify_bilingual.py` 双向体检：英文侧不许残留中文，中文侧不许漏条、不许
只是把英文抄一遍。

下拉是**逐个登记**的：本包 23 个带下拉的节点、40 个下拉输入、347 条选项值全部有中文名
（含翻译节点的 106 个语言码，`af` 显示成「南非荷兰语」）。文件名、模型名这类列表和
`JPEG` / `PNG` 这种中英同形的值是刻意不翻的。

节点菜单里的分类名后端写英文（`QG-tools/Loaders`、`QG-tools/Mask`），中文界面的
「加载器」「遮罩」来自插件自带的 `locales/zh/main.json` 里的 `nodeCategories`
—— 这是 ComfyUI 自己的分类翻译通道，跟节点标题一样，不用装汉化插件。

下拉选项的**值是英文**（`on-white` 这类），中文界面显示的是对应的中文译名（`合成白底`）。
存进工作流的是英文值，所以同一份工作流在两种界面下都能跑，也不会因为换界面而失效。
v0.9.4 之前的存档存的是中文选项值，打开时前端会就地换成英文值；绕过前端
（API 直连、脚本批量跑）也照样能执行，节点内部还会再兜一次。

## 中英文搜索：别名与排序机制

节点标题跟着界面语言走（中文界面 `添加水印`、英文界面 `Add Watermark`），
**中英文都能搜到**：中文靠语言包里的译名，英文靠标题本身。除此之外每个节点还登记了一组
口语叫法（`web/shared/node_aliases.mjs`），页面加载时写进节点定义的 `search_aliases`，
ComfyUI 的搜索框会把它们和标题一起做模糊匹配。

中文名里带空格的节点（比如 `空 Latent 分辨率`）另登记了**无空格写法**：
敲 `空latent`、`空Latent`、`空latent分辨率` 都能搜到。
只按字面子串比的话，`空 latent` 命中而 `空latent` 不命中，所以这层变体是必要的。

想加词就改 `web/shared/node_aliases.mjs` 里对应节点那一行，刷新页面即可。

**命中别名的节点会往前提一点，但最多 2 个**：搜索框只取前 64 条，
而 `text` 这类词能命中 480 多个节点，QG 文本原本排第 159 名——等于搜不到。所以扩展会把
「别名里正好有这个词」的 QG 节点提到前面，最多提 2 个，其余保持原位。

搜 `image` 这种上位词时，登记了该词的 QG 图像类节点会被提到前面（最多 2 个）；
搜 `text` 时是 `QG 文本`、`QG 文本按分隔符分割` 排前两位。不想看到这个行为的话，
把 `web/shared/node_aliases.mjs` 末尾那几个上位词（`image` / `mask` / `size` / `model` /
`document` / `workflow` / `text`）删掉即可，节点自己的英文名还会保留。

## 纯前端注册节点的适配

工作流说明卡与工作流开关在源包是纯前端注册（`python_module` 写 `custom_nodes.frontend_only`），
节点右上角有绿色 `frontend_only` 徽标。本包每个节点都有后端定义（打包、语言包、尺寸表
都靠 `nodes/*.py` 对齐），所以补了两个空壳类，那个徽标不再显示。行为不变 ——
`isVirtualNode` 仍然成立，两个节点照样不进 prompt、不执行。

## 与 AusBoss 互通的内部标识

重绘缝合的槽类型是 `AUSBOSS_STITCHER`、数据里的 `kind` 是 `ausboss_inpaint_stitcher`，
这两个字符串**故意保留原样**：两个插件都装时，任意一边的裁剪都能喂任意一边的缝合，
结果逐像素一致（`tools/_check_stitch_inpaint.py` 里 52 项断言守着这条）。改名会让两边
互相不认识，老工作流直接断线。

## 裁剪恢复：按孤海口径对齐

QG_MaskCrop / QG_CropRestore 的裁剪与贴回链路按孤海口径对齐过；
这些改动只在裁剪恢复链路生效，不改变 `QG_ImageMergeMask` 等其他节点的缩放口径：

- **裁剪中心**：`plan_crop()` 用「四向扩展后矩形的中心」定位裁剪框，和孤海
  `遮罩裁剪V2` 一致，而不是原遮罩 bbox 的中心。扩展不对称时（上扩 197px、下扩 263px）
  旧口径会让取景偏 33px；同一遮罩同一参数下，两边裁框现在逐像素相同。
- **缩放**：`resize_image_aa()` 缩小时仍用 area，放大时改成 antialiased bicubic（再 clamp），
  更接近孤海 `Image.LANCZOS` 的往返结果；包内通用 `resize_image()` 保持原样。
- **百分比口径**：CropRestore 的「遮罩扩张」「羽化」与孤海一样，是**涂色区域平均边长的百分比**，
  不是固定像素。`percent_to_pixels()` 用 `int((w+h)/2 × 百分比 / 100)`，最小 1px，
  所以孤海工作流里的 4%/5% 在 QG 里填 4/5 就是同一尺度。
- **扩张**：`expand_mask_euclidean()` 用逐行圆盘并集做欧氏扩张，对应孤海
  `cv2.distanceTransform(1-fg, DIST_L2, 3) <= radius`，而不是普通方形膨胀。
- **羽化**：`feather_mask_softtail()` 的核外半段用 smoothstep 平滑收尾；
  `fade_mask_at_crop_edges()` 再对落在画布内部的裁剪边做 smoothstep 淡出，避免硬缝。
- **校色**：`match_colour()` 先降采样到 256 边，用高频残差算结构权重，再以
  「单通道差 ≤ 24/255、明度差 ≤ 18/255、结构权重 > 0.8」筛候选，3×3 腐蚀后要求样本 ≥ 5%；
  之后做 6 轮鲁棒 gain/offset 拟合（增益 0.9~1.1、偏移 ±24/255），稳定样本不足 60% 就整块放弃。
- **贴回**：`stitch_back()` 在羽化过渡区加确定性 `<1/255` 抖动，数字限制在两张源图之间，
  避免 uint8 截断时整圈少一级灰度。

离线门禁 `_check_match_colour.py` 12 项、`_exp_align_guhai.py` 19 项；后者与孤海
`匹配裁剪颜色` 在真实案例上的平均差约 0.00294（0~1 刻度）。
`tools/_compare_qg_vs_guhai_nodes.py` 用同一张图、同一个遮罩、同一组参数跑两边节点，
裁框、裁剪图、贴回图都逐项对照，报告落在 `dist/裁剪恢复双节点对照-QGvs孤海-*.md`。
